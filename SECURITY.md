# Security policy

SuperCLI runs developer commands and community plugins with the current user's
permissions. Install plugins only from sources you trust and inspect manifests
before use. Never place credentials in repository configuration or examples.

Please report vulnerabilities privately through GitHub Security Advisories for
this repository. Include the affected version, platform, reproduction and
impact. Do not publish credentials, company information or a working exploit in
a public issue.

The current supported line is `0.3.x-alpha`. Security fixes are released on the
latest alpha while the project is pre-1.0.
