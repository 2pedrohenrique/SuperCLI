# Support

SuperCLI is community-supported and currently in alpha.

- Use GitHub Discussions for setup questions and ideas, when enabled.
- Use an issue for reproducible bugs and feature proposals.
- Use GitHub private vulnerability reporting for security concerns; see
  [SECURITY.md](SECURITY.md).

Before reporting a bug, run `supercli --version`, reproduce with a minimal
sanitized configuration, and remove project names, private paths, hosts, logs,
tokens and credentials. Never upload your personal `supercli.yaml` unchanged.
